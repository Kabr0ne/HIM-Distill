# HIM-Distill
## Création d'un HIM pour une colonne à distiller, en utilisant un microcontrôleur et une raspberry pi.
### Vue d'ensemble du projet :
- Création d'une interface tactile en python à partir d'un schéma d'un colonne à distiller (5 sondes de températures à afficher en temps réel, 3 à 6 interrupteurs)
- Mise en place du système de collecte de données (5 sondes de températures)
- Mise en place d'une base de donnée
- Exportation des données d'une ou plusieurs sondes sur un support USB

### D'autres fonctionnalitées pourront être ajoutés/modifiés
